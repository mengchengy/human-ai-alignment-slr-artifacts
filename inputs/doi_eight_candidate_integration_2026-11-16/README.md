# Fixed 201-cluster inputs

These two workbooks are fixed inputs for the build scripts in this repository. They contain 201 study-contribution clusters, including P311–P318, which were added to the 193-cluster baseline. The corresponding integration increased the report count from 194 to 202 and the cluster count from 193 to 201.

The original script that created these workbooks was not found in the project files. This note records their known provenance; it does not reproduce the integration step. The workbooks should therefore be treated as frozen inputs, not as independently rebuilt outputs.

The later build steps add P319 and then P320–P322 to produce the thesis versions of S1 and S2. The final thesis workbooks are stored in the repository root.
